
## ⚠️ Important Notes

### Mock Files Must Be Generated

Before running tests for the first time, you MUST generate mock files:

```bash
dart run build_runner build --delete-conflicting-outputs
```

This creates:
- `test/unit/favorites_cubit_test.mocks.dart`
- `test/unit/favorites_repository_test.mocks.dart`
- `test/unit/home_cubit_test.mocks.dart`
- `test/unit/home_repository_test.mocks.dart`

**Why?** These files don't exist yet because they're generated by `build_runner`. Without them, tests will show errors.

### Expected Errors Before Mock Generation

Until you run `build_runner`, you'll see:
- ❌ "Target of URI doesn't exist: 'xxx_test.mocks.dart'"
- ❌ "Undefined class 'MockXxx'"

**This is normal!** Just run the mock generation command above.

## 📝 Testing Patterns Used

### 1. Repository Testing
```dart
test('should return Right when successful', () async {
  // Arrange
  when(mockApi.method()).thenAnswer((_) async => data);
  
  // Act
  final result = await repository.method();
  
  // Assert
  expect(result, Right(data));
  verify(mockApi.method()).called(1);
});
```

### 2. Cubit Testing (BlocTest)
```dart
blocTest<MyCubit, MyState>(
  'emits [loading, success]',
  build: () => cubit,
  act: (c) => c.load(),
  expect: () => [
    MyState(status: Status.loading),
    MyState(status: Status.success),
  ],
);
```

### 3. Model Testing
```dart
test('should serialize and deserialize', () {
  final original = Model(field: 'value');
  final json = original.toJson();
  final result = Model.fromJson(json);
  
  expect(result.field, original.field);
});
```

## 🔧 Troubleshooting

### Issue: Mock files not found
**Solution:** Run `dart run build_runner build --delete-conflicting-outputs`

### Issue: Build runner hangs
**Solution:** 
1. Cancel (Ctrl+C)
2. Run `flutter clean`
3. Run `flutter pub get`
4. Try again

### Issue: Tests fail
**Solution:**
1. Ensure mocks are generated
2. Check all dependencies are installed
3. Read error messages carefully
4. Check `TESTING_SETUP_GUIDE.md` for detailed help
